## Development Experience

### .NET

**A2 (Software Engineer) — Intermediate [Core]**
  - has hands-on experience in .NET application development
  - able to design and develop hierarchies of custom types using appropriate access modifiers and overloading/overriding
  - able to develop custom generic types or their hierarchy with appropriate constraints
  - able to describe difference Reference Types vs Value Types
  - able to develop LINQ-compatible methods
  - understand lazy evaluation and able to implement lazy methods
  - able to run a piece of code on another thread using different methods (TPL, Thread, ThreadPool, etc)
  - able to use synchronization primitives
  - can properly implement IDisposable
  - able to choose between class and struct
  - has hands-on experience with .NET collections
  - aware of .NET collections algorithmic complexity
  - aware of strong-named assemblies
  - aware of InternalVisibleTo
  - aware of covariance and contravariance in generics
  - able to explain what is CLR, JIT, Roslyn and how GC works
  - understands how to decompile code into IL

**A3 (Senior) — Advanced [Core]**
  - able to conduct TI
  - able to troubleshoot performance issues in .NET applications
  - able to establish a logging approach
  - able to work with dump files and collect them
  - able to explain common root causes of memory leaks and deal with them
  - able to use analyzing and profiling tools
  - able to use expressions

**A4 (Lead) — Expert [Core]**
  - able to conduct TI
  - able to configure GC
  - able to contribute into .NET community
  - able to consult or organize tech talk on multithreading, GC topics

### SQL

**A2 (Software Engineer) — Novice [Required]**
  - Able to describe the purpose of SQL and name the main SQL concepts
  - Able to use DQL for querying data
  - Able to use DDL to manage database entities (create a database structure according to a database schema; alter tables)
  - Able to create indexes for a database table
  - Able to describe the purpose and types of joins
  - Able to name main types of database indexes (clustered, non-clustered, unique, non-unique, single column, multicolumn, full table, filtered)
  - Able to create views, stored procedures, and triggers, and manage them
  - Able to use TCL to start, commit, and rollback transactions
  - Aware of 3 normalizations forms
  - Aware of transaction isolation levels

**A3 (Senior) — Intermediate [Required]**
  - Able to use complex queries (sub-queries, joins, groupby & having) and queries with analytic functions- Able to use queries with set operations
  - Able to perform several query realizations for the task
  - Understands how indexes work, the difference between clustered, and non-clustered, what a page is and how they layout
  - Knows what causes deadlocks and how to avoid them
  - Can generate complex data reports via group bys with aggregate functions
  - Able to use DCL to manage user access in a database
  - Able to analyze a query cost and performance, identify what can be improved, basic experience on performance improvements
  - Knows how to use triggers
  - Able to explain the difference between SQL and NoSQL approaches, pros and cons
  - Able to explain what problem different isolation level solve'

**A4 (Lead) — Advanced [Required]**
  - Has experience in using complex queries and queries with analytic functions
  - Has experience with query performance optimization
  - Can read an execution plan, and understand how the different parts of the query affect it, have experience with making decisions based on execution plan
  - Can tune queries with execution hints without screwing up performance
  - Can profile and use traces for identifying and understanding statistics of executions under real-world load
  - Can use performance counters and understand what the database load and behavior is from monitoring them
  - Knows how to use triggers and how to use them safely, with minimal risk
  - Understands when and how to denormalize a database
  - Knows how to use distributed transactions even with layers'

  - understand the main points of clear standard speech on familiar topics that are often met in work, education, holiday, etc;

  - produce simple connected text on topics that are familiar or of personal interest;
  - produce a simple connected text (e.g. essay, article) on a range of familiar topics by linking a series of shorter elements into a longer structured whole;
  - give their impressions, feelings and opinions on a range of personal interest topics (e.g. lifestyles, culture, stories), describe everyday aspects of their life/work/experiences, list advantages and disadvantages, with simple words and expressions.

  - produce reasonably detailed texts on a variety of familiar topics, combining and evaluating information from different sources, explaining a viewpoint on an issue and giving the advantages and disadvantages of different options;
  - produce a detailed description of a complex process, write a report or article developing an argument, giving reasons and explaining advantages and disadvantages.
